## 先回答：需不需要 GitHub 登录？

| 方案 | 用户体验 | 开发量 | 用户追踪 | 推荐 |
|------|---------|--------|---------|------|
| **不需要登录** — 直接内置免费 Key | ⭐⭐⭐⭐⭐ 零门槛 | 极低 | ❌ 不知道谁在用 | 适合冷启动 |
| **New API 自建账号** — 用户去面板注册 | ⭐⭐⭐ 要跳转网页注册 | 低 | ✅ | 够用 |
| **GitHub 登录** — 扩展内一键登录 | ⭐⭐⭐⭐ 体验好 | 中 | ✅ | **推荐** |

### 我的建议：两阶段走

```
第一阶段（现在）：内置免费 Key，零门槛，先拉用户
第二阶段（用户量起来后）：加 GitHub 登录，追踪用户 + 防滥用
```

## 如果加 GitHub 登录，怎么做？

VS Code 扩展做 OAuth 有个限制：**扩展不能跑 HTTP 服务器**。所以需要一个中转回调页面。

### 完整流程

```
用户点「GitHub 登录」
      │
      ▼
扩展调用 vscode.env.openExternal() 打开浏览器
      │
      ▼
跳转 GitHub 授权页 → 用户点「Authorize」
      │
      ▼
GitHub 回调到你的服务器 callback 页面
      │
      ▼
callback 页面把 code 发给你的后端 → 换 token → 查/创建用户 → 生成 MIMO API Key
      │
      ▼
callback 页面通过 vscode URI scheme 把 Key 传回扩展
      │
      ▼
扩展存储 Key，完成登录
```

### 架构图

```
┌─────────────┐     ┌──────────┐     ┌───────────┐
│  VS Code    │     │  GitHub  │     │  你的服务器 │
│  MIMO 扩展  │────→│  OAuth   │────→│  callback  │
│             │←────│          │←────│  页面      │
└─────────────┘     └──────────┘     └───────────┘
                                            │
                                            ▼
                                     ┌───────────┐
                                     │  New API  │
                                     │  用户管理  │
                                     └───────────┘
```

### 需要三个东西

**① GitHub OAuth App（免费）**

去 GitHub → Settings → Developer settings → OAuth Apps → New

| 配置项 | 填写 |
|--------|------|
| Application name | MIMO Agent |
| Homepage URL | `https://your-domain.com` |
| Authorization callback URL | `https://your-domain.com/auth/github/callback` |

拿到 `Client ID` 和 `Client Secret`

**② 一个回调页面（几十行代码）**

```html
<!-- hosted at https://your-domain.com/auth/github/callback -->
<script>
  // 从 URL 拿到 code
  const code = new URLSearchParams(location.search).get('code');
  
  // 发给后端换 token
  fetch('https://your-domain.com/api/auth/github', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ code })
  })
  .then(r => r.json())
  .then(data => {
    // 通过 VS Code URI scheme 传回扩展
    // mimo-agent://auth?token=xxx&key=sk-xxx
    location.href = `vscode://yshome.mimo-agent/auth?token=${data.token}&key=${data.apiKey}&github=${data.githubName}`;
  });
</script>
```

**③ 后端一个接口（加在你的服务器上）**

```typescript
// POST /api/auth/github
// 1. 用 code 换 GitHub access_token
// 2. 用 access_token 获取用户信息（用户名、头像）
// 3. 在 New API 里查/创建这个用户
// 4. 生成一个 New API 的 API Key 绑定给这个用户
// 5. 返回 { token, apiKey, githubName }
```

### 扩展端改动（很少）

```typescript
// 在扩展激活时监听回调
vscode.window.registerUriHandler({
  handleUri(uri: vscode.Uri) {
    if (uri.path === '/auth') {
      const params = new URLSearchParams(uri.query);
      const apiKey = params.get('key');
      const githubName = params.get('github');
      // 存储
      saveSetting('api.api_key', apiKey);
      vscode.window.showInformationMessage(`欢迎, ${githubName}!`);
    }
  }
});

// 登录按钮
function loginWithGitHub() {
  const clientId = '你的Client ID';
  const redirectUri = 'https://your-domain.com/auth/github/callback';
  const scope = 'read:user';
  const authUrl = `https://github.com/login/oauth/authorize?client_id=${clientId}&redirect_uri=${redirectUri}&scope=${scope}`;
  vscode.env.openExternal(vscode.Uri.parse(authUrl));
}
```

## 实际建议

| 你的情况 | 建议 |
|---------|------|
| 先跑起来拉用户 | **现在不要加登录**，直接内置免费 Key |
| 用户量 > 100 | 加 New API 自建账号（最简单） |
| 用户量 > 1000 | 加 GitHub 登录（体验好、能追踪） |

**你打算现在就加 GitHub 登录，还是先跑起来再说？**
